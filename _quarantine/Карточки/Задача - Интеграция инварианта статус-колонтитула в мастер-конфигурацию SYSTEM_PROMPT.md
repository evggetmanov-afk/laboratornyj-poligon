# Задача: Интеграция инварианта статус-колонтитула в мастер-конфигурацию SYSTEM_PROMPT

## 1. Контекст и основание
* **Связанный инвариант:** `Карточки/Инвариант - Ролевые слэш-команды интерфейса статус-колонтитул и реестр ролей.md` (п. 3.1).
* **Суть требования:** Каждый исходящий ответ ассистента обязан детерминированно маркироваться строкой:
  `[Цикл: N | Роль: <Имя_Роли> | Такт: <Думаем/Делаем>]` с последующим разделителем `---`.
* **Текущий статус:** Правило соблюдается в оперативной памяти диалога, но требует персистентного заземления в мастер-промпт среды, чтобы автоматически наследоваться новыми сессиями и агентами.

## 2. Предмет исследования и развилки
* Определить канонический файл-источник мастер-промпта в репозитории:
  - Вариант A: Корневой `SYSTEM_PROMPT.md` или `.system/prompt.md`.
  - Вариант B: Активный шаблон в каталоге `prompts/` под управлением скрипта `sync_prompts.py`.
  - Вариант C: Конфигурация системных инструкций Aider / CLI-ассистента.

## 3. Целевой блок для внедрения (Спецификация)
```markdown
### Инвариант вывода: Обязательный статус-колонтитул
Каждый ответ модели БЕЗ ИСКЛЮЧЕНИЙ обязан начинаться с первой строки строгого формата:
`[Цикл: N | Роль: <Имя_Роли> | Такт: <Думаем/Делаем>]`
---
(Далее следует основное тело ответа)
```

## 4. Критерии закрытия задачи (Definition of Done)
1. Локализован точный путь физического файла мастер-промпта.
2. Блок спецификации статус-колонтитула добавлен в мастер-файл через Safe Atomic Write.
3. Проверена работа скрипта синхронизации (если задействован `sync_prompts.py`).
4. Статус данной карточки переведён в `выполнено`.
