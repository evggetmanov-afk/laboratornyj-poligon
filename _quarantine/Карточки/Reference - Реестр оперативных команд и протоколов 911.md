# Реестр оперативных команд и протоколов 911

Единая оперативная шпаргалка быстрого реагирования. Предназначена для мгновенной ориентации оператора при дефиците памяти и заминках в управлении контуром.

## 1. Экстренный вызов службы 911
* **Словесные фразы:** «911», «SOS», «Помоги», «Я забыл», «Что нажимать?», «Как это вызвать?», «Где я?»
* **Слэш-команды:** `/911`, `/sos`, `/help`
* **Действие системы:** Выдача краткой подсказки нужной фразы или кнопки без лишней теории.

## 2. Базовые протокольные рычаги
* **`+++`** или **`Делаем`** или **`пиши код`** — переход из такта «Думаем» в такт «Делаем» (разрешение на генерацию кода и запись файлов).
* **`==`** — квитирование успешного выполнения терминальной команды без ошибок (сигнал ожидания следующей задачи).
* **«Консервируем замысел»** или **«Паркуем контекст»** — упаковка текущей отложенной идеи в атомарную карточку бэклога без потери фокуса.
* **«Сдать смену»** или **«Закрыть вахту»** — запись журнала вахты, проверка Git Remote Guard и сборка свежего контекста через `vahta.py`.

## 3. Словесные команды управления ролями
* **«Включи критика»** (или `/критик`, `/red`) — отключение похвалы, жесткий поиск уязвимостей и точек отказа (Red Teaming).
* **«Сценарий провала»** (или `/вскрытие`, `/pre-mortem`) — разбор причин гипотетического краха через 6 месяцев до начала работ.
* **«Сравни варианты»** (или `/сравни`, `/vs`) — слепое сопоставление двух решений без маркеров авторских симпатий.
* **«Проверь предпосылки»** (или `/проверь`, `/cov`) — декомпозиция и пошаговая проверка базовых фактов до вынесения вердикта.
* **«Верни архитектора»** (или `/архитектор`, `/сброс`) — возврат в стандартный конструктивный режим совместного проектирования.

## 4. Сниппеты Raycast (быстрый ввод в поле текста)
* `;red` — разворачивает текст директивы стресс-теста (Red Teaming).
* `;fail` или `;post` — разворачивает директиву сценария провала (Pre-Mortem).
* `;vs` — разворачивает шаблон слепого сопоставления.
* `;cov` — разворачивает шаблон пошаговой верификации предпосылок.

## 5. Терминал и системные алиасы
* `вахта` — сборка актуального контекста вахты в буфер обмена (`pbcopy`) со звуком `Pop.aiff`.
* `пом` — запуск Aider CLI для правок файлов в репозитории.
