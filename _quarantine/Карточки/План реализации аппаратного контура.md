# План реализации аппаратного контура захвата

Опорный план декомпозиции задач текущего кванта в рамках вехи `VEHA-2026-09-28-SKILLS-ARCHITECTURE`. Обеспечивает связку физического пульта оператора, видеопотока с покадровой точностью, фиксации опорного/безопорного статуса удара, позиционирования на корте и аналитического контура базы знаний.

---

### Этап 1. Архитектурная карточка: Интеграция Stream Deck и Video Shuttle
* **Целевой файл:** `Карточки/Hardware - Stream Deck & Video Shuttle Integration.md`
* **Ключевые блоки спецификации:**
  1. **Видеоядро и транспорт:** Выбор `mpv` в качестве базового плеера с управлением через UNIX IPC-сокет (`/tmp/mpvsocket`).
  2. **Метрология кадров:** Прямой съем параметров `estimated-frame-number`, `time-pos` и `container-fps` без промежуточных GUI-задержек.
  3. **Три режима плотности захвата (Capture Modes):**
     * **Режим 1: Ключевой инцидент (Key Incident 4-Shot):** фиксация фаз разгона, точки контакта и окончания удара для критических розыгрышей.
     * **Режим 2: Трекинг темпоритма ралли (Rally Cadence Tracker, 4+ ударов):** сквозная ритмическая фиксация точек контакта каждого удара (Удар 1..N) одной кнопкой для замера темпа и скорости обмена.
     * **Режим 3: Экспресс-оценка (Voice-Only Triage):** фиксация таймкода и надиктовка голосом экспертной оценки без покадровой сетки при типовых штатных эпизодах.
  4. **Модификатор работы ног (Footwork Status):**
     * Выделенная аппаратная кнопка (или голосовой маркер) для фиксации **безопорного удара** (удар в воздухе, на отвале, потеря опоры под прессингом темпа).
     * Значение по умолчанию — опорный удар (сохранение статического баланса).
  5. **Автомат прерываний и терминации:**
     * Развилка закрытия: детерминированные кнопки исходов vs клавиша-прерыватель со сбросом и голосовой надиктовкой.
     * Обработка служебных ситуаций: `1st Fault`, `Double Fault`, `Let (Replay)`.
  6. **Структура события (Event Payload):** JSON/YAML-событие с кадровыми метками, статусом подачи, меткой footwork (`grounded` vs `airborne`), аудиозаметкой и координатами на корте.

### Этап 2. Спецификация инструмента: Нарезка клипов и телеметрия кадров
* **Целевой файл:** `Карточки/Tool - Frame Telemetry & Video Clip Slicer.md`
* **Ключевые блоки спецификации:**
  1. **Адаптивный конвейер медиа:**
     * *Для Режима 1:* экстракция ключевых кадров + клип инцидента. Экспорт кадра контакта высокого разрешения для распознавания положения на корте.
     * *Для Режима 2:* сквозной клип розыгрыша и вычисление временного ряда интервалов между контактами.
     * *Для Режима 3:* сохранение только аудиодорожки надиктовки без нарезки изображений.
  2. **Оптическое позиционирование на корте (Court Positioning — Этап 1):**
     * Определение положения игрока относительно корта в момент контакта (вход внутрь корта / задняя линия / глубина отката в метрах, смещение в коридор / центр).
     * Микроанатомия суставов исключена из первой очереди реализации.
  3. **Аудиотранспорт:** Локальная запись микрофона по прерывателю и транскрибация через `whisper CLI`.
  4. **Файловая организация:** `assets/clips/` для видео/кадров, `assets/audio/` для аудиозаметок, сквозная привязка по ID инцидента.
  5. **Паспорт телеметрии:** Запись во Frontmatter расчетных дельт времени, ряда темпоритма, координат позиции на корте (`court_zone`) и статуса опоры (`footwork: grounded | airborne`).

### Этап 3. Системный промпт: Извлечение тактических скиллов
* **Целевой файл:** `Карточки/Prompt - Tactical Blitz Skill Extraction.md`
* **Ключевые блоки спецификации:**
  1. **Аналитическая роль:** Системный тренер-аналитик (геометрия корта, устойчивость опоры на высоком темпе как признак класса, статический баланс в точке контакта, когнитивная адаптация).
  2. **Входной контракт:** Маршрутизация трех типов входящих данных:
     * Ветка 1 (Инцидент + Позиция + Опора): кадры контакта + глубина на корте + флаг опорного/безопорного удара.
     * Ветка 2 (Темпоритм + Опора): сопоставление дельт времени и способности сохранять опорные удары при сжатии интервалов.
     * Ветка 3 (Голосовой вердикт): фактологическая экспертная оценка.
  3. **Выходной контракт:** Карточка скилла или тактического дефекта (например: *«Срыв кинетической цепи: вынужденный безопорный удар на третьем мяче при сокращении времени реакции до 0.92с»*).
