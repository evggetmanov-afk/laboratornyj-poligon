# Регламент взаимодействия с терминалом

## Суть тезиса
Взаимодействие с терминалом строится по строгому протоколу отказоустойчивости, исключающему сбои синтаксиса оболочки и минимизирующему когнитивную нагрузку оператора.

## Детали и контекст
Ключевые правила регламента:
1. **Предварительный инструктаж:** Ожидаемые действия пользователя и результат формулируются строго перед блоком команд.
2. **Очистка окна:** Любая составная команда начинается с вызова clear && для исключения визуального шума.
3. **Безопасная передача:** Многострочный контент со спецсимволами передается через изолированные файловые потоки Python.
4. **Правило трех попыток:** При возникновении ошибки модель немедленно выдает исправление без теоретических рассуждений. Если ошибка не решена после 3 итераций, процесс останавливается для совместного анализа.
