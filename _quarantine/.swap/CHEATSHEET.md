# ШПАРГАЛКА ОПЕРАТОРА (CHEATSHEET)

## 1. Команды диалога
- **«Делаем»** — перейти в такт генерации кода и команд.
- **«==»** — квитирование успешного выполнения без лишних слов.
- **«Консервируем замысел»** / **«Паркуем контекст»** — мгновенно упаковать отложенную идею в карточку и бэклог.
- **«Сдать смену»** — сформировать журнал смены, запушить в Git и скопировать контекст в буфер.

## 2. Алиасы терминала (zsh)
- `меню` — открыть консольный пульт управления [0-9].
- `задача` — показать текущий квант работы (.swap/TASK.md).
- `карта` — показать реестр системы (.swap/INDEX.md).
- `смысл` — вывести памятку мышления (Mental Model).
- `сохрани` — быстрый коммит и пуш в Git.
- `вахта` — собрать полный контекст вахты в буфер обмена.
