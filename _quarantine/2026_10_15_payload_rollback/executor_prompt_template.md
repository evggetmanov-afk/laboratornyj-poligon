# Спецификация: Шаблон стартового пакета чата-исполнителя (Чат 2)

## 1. Назначение
Стартовый пакет для изолированного чата-исполнителя (Чат 2) для выполнения кванта задачи (.swap/TASK.md) за один такт.

## 2. Инварианты
1. Предварительная санкция: Запрос содержит явную санкцию («пиши код», «делай»). Защитный барьер снят.
2. Однотактный формат: Строго готовый код/файл и одна команда Definition of Done без вступительных и завершающих фраз.
3. Соблюдение стандарта specs/terminal_heredoc_standard.md.
4. Протокол физической реальности: Не утверждать о факте записи до получения лога терминала.
