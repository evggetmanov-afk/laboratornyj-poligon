# Спецификация: Штатный шлюз генерации файлов (Python Payload Protocol)

## 1. НАЗНАЧЕНИЕ
Штатный механизм пакетного создания и обновления проектных файлов и заметок без риска повреждения терминальных сессий невидимыми символами.

## 2. ДВУХУРОВНЕВАЯ МОДЕЛЬ (АРХИТЕКТУРНЫЙ ИНВАРИАНТ)
- **Уровень 1 (Аварийный / Ядро):** Редактирование файлов ядра (`PROJECT_PASSPORT.md`, `specs/`, `scripts/`) и аварийное восстановление производятся через проверенный Heredoc (`cat << 'EOF'`).
- **Уровень 2 (Штатный / Проекты):** Пакетная генерация кода, карточек и тестов в `projects/` и во внешних контурах производится через блоки полезной нагрузки и скрипт `scripts/apply_payload.py`.

## 3. ФОРМАТ БЛОКОВ
Открывающий тег строго с начала строки, без символов закрытия в строке пути:
<<<FILE_PATH: относительный/путь/к/файлу.расширение
[содержимое файла байт-в-байт]
<<<FILE_CONTENT_END>>>

## 4. ИСПОЛНЕНИЕ
Скрипт запускается оператором в терминале:
- По умолчанию (читает .swap/TASK.md): `python3 scripts/apply_payload.py`
- Из произвольного файла: `python3 scripts/apply_payload.py путь/к/файлу.md`
