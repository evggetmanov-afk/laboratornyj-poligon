# Инструмент: clip_to_inbox (.scripts/clip_to_inbox.sh ➔ clip_to_inbox.py)

## 1. Суть
Быстрый сброс текстового сырья из буфера обмена в каталог первичного приема `Входящие/`.

## 2. Способы вызова
- **Пункт меню:** Пункт в меню оператора
- **Прямой путь:** `.scripts/clip_to_inbox.sh`

## 3. Алгоритм работы
1. Извлекает текст из буфера через `pbpaste`.
2. Генерирует файл во `Входящие/inbox_YYYYMMDD_HHMMSS.md`.
3. Записывает сырье с метаданными времени создания.

## 4. Входы и выходы
- **Входы:** Содержимое буфера обмена macOS (`pbpaste`).
- **Выходы:** Новый файл во `Входящие/`.

## 5. Диагностика сбоев
- *Симптом:* Буфер пуст или не содержит текста.
  - *Решение:* Скопировать текст перед вызовом.
