# Инструмент: append_to_daily (.scripts/append_to_daily.sh ➔ append_to_daily.py)

## 1. Суть
Дозапись оперативной мысли или строчки лога в ежедневный журнал без ручного открытия файлов.

## 2. Способы вызова
- **Прямой путь:** `.scripts/append_to_daily.sh "Текст записи"`

## 3. Алгоритм работы
1. Принимает аргумент командной строки.
2. Определяет целевой файл текущего дня в `Вахтенный_журнал/`.
3. Дописывает строку с таймштампом в конец файла.

## 4. Входы и выходы
- **Входы:** Строка текста из параметров вызова.
- **Выходы:** Дополненный файл суточного журнала.

## 5. Диагностика сбоев
- *Симптом:* Запись не добавилась.
  - *Решение:* Убедиться, что текст записи передан в кавычках.
