# Инструмент: shift_note (.scripts/shift_note.py)

## 1. Суть
Создание стандартизированного шаблона заметки рабочей смены в каталоге `Вахтенный_журнал/`.

## 2. Способы вызова
- **Прямой путь:** `python3 .scripts/shift_note.py`

## 3. Алгоритм работы
1. Генерирует имя файла по текущей дате и времени.
2. Проверяет наличие каталога `Вахтенный_журнал/`.
3. Создает файл по каноническому шаблону (Цель, Контекст, Артефакты, Статус).

## 4. Входы и выходы
- **Входы:** Системное время macOS.
- **Выходы:** Созданный `.md` файл в папке журнала.

## 5. Диагностика сбоев
- *Симптом:* Ошибка записи файла.
  - *Решение:* Проверить наличие папки `Вахтенный_журнал/` и права доступа к ней.
