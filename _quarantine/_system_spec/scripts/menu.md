# Инструмент: menu (.swap/bin/menu)

## 1. Суть
Интерактивный циклический пульт диспетчера для вызова ключевых операций полигона без ввода CLI-команд.

## 2. Способы вызова
- **Алиас:** `меню`
- **Прямой путь:** `.swap/bin/menu`

## 3. Алгоритм работы
1. Очищает экран терминала (`clear`) и выводит нумерованный список доступных операций.
2. Считывает выбор оператора.
3. Выполняет целевой скрипт или команду Git.
4. Ожидает нажатия Enter для возврата на главный экран. Выход по `0` или `q`.

## 4. Входы и выходы
- **Входы:** Нажатие клавиш `0-9` с клавиатуры.
- **Выходы:** Вывод статусов утилит в терминал, вызовы `pbcopy` и браузера.

## 5. Диагностика сбоев
- *Симптом:* «Permission denied».
  - *Решение:* `chmod +x .swap/bin/menu`.
