# Инструкция пользователя

## 1. Заступление на вахту и состав пакета контекста
* **Инициализация:** Запуск нового чистого треда чата с ассистентом.
* **Вызов утилиты:** Использование терминальной команды `вахта` (или скрипта `.scripts/vahta.sh`) для автоматической сборки контекста.
* **Состав «пакета вахты» (что передается в буфер обмена `pbcopy`):**
  1. **Главный системный контракт:** `Система/Промпты/Системный_Промпт.md` (базовые правила, дисциплинарные барьеры и запрет на генерацию кода без явного триггера).
  2. **Протокол заступления:** `Система/Промпты/Протокол_Заступления_На_Вахту.md` (инструкция для нового ассистента по входу в контур).
  3. **Актуальная карточка смены:** Самый свежий разовый файл из директории `Вахтенный_журнал/` (итоги предыдущей сессии, нерешенные задачи и статус репозитория).
* **Аудиоиндикация:** Успешная сборка сопровождается системным звуком `Pop.aiff`.
* **Принятие смены:** Вставка скопированного пакета в новый чат.

## 2. Оперативная работа и управление потоками информации
В течение дня вы управляете информацией с помощью следующих команд-триггеров:
* **Фиксация во входящих (дневник или разовая заметка):**
  * *Команда:* «Запиши текущую мысль как дополнение дневника» или «Создай разовую заметку по [теме] во входящих».
  * *Результат:* Ассистент создает или обновляет файл в каталоге `Входящие/`.
* **Создание карточки знаний:**
  * *Команда:* «Оформи итоги нашего обсуждения в виде атомарной карточки в папке Карточки/ со статусом "сырое"».
  * *Результат:* Создается файл в `Карточки/`, который начинает отображаться в дашборде `Хроника_Полигона.md`.
* **Изменение статуса карточки:**
  * *Команда:* «Обнови статус карточки [название] на "обработано" (или "проверено")».
* **Такт «Думаем» / «Делаем»:**
  * Обсуждение идет в такте **«Думаем»** (код не пишется). Переход к записи файлов выполняется по команде **«Делаем»** строго через безопасный метод `cat << 'EOF'`. В момент перехода к такту «Делаем» и записи файлов фиксируется состояние рабочей директории.

## 3. Процедура сдачи смены
Для фиксации результатов и защиты от деградации контекста отдается команда **«Сдать смену»**:
1. **Формирование разового файла смены:** Фиксация итогов в новом файле `Вахтенный_журнал/Журнал YYYY-MM-DD.md`.
2. **Фиксация и Remote Guard:** 
   * Добавление изменений в индекс (`git add ...`).
   * Создание локального коммита (`git commit -m "..."`).
   * Отправка в удаленный репозиторий (`git push origin main`) — выполняется исключительно при сдаче смены.
   * Проверка паритета: команда `git status` должна вернуть обязательную строку `Your branch is up to date with 'origin/main'`.
3. **Сборка контекста:** Вызов утилиты вахты для подготовки следующей сессии.

## 4. Обработка ошибок (Logging First)
* При сбое в терминале немедленно используйте команду для фиксации инцидента или горячую клавишу скрипта захвата `.scripts/capture_error.py` перед любыми исправлениями.
