# Витрина архитектуры конвейера (Реестр инвариантов)

> **Автономный контур:** витрина формируется динамически на основе метаданных заметок.

---

## 1. Экспресс-контроль и алерты ревизии (Linter)

```dataview
TABLE WITHOUT ID
  file.link AS "Карточка",
  статус AS "Статус",
  дата AS "Дата ревизии",
  choice(
    !id OR !статус OR !дата, "Заполнить обязательные метаданные (id, статус, дата)",
    choice(статус = "на_пересмотре", "Завершить модернизацию и утвердить узел",
    choice((date(today) - date(дата)).days > 14, "Провести плановую сверку инварианта (срок > 14 дней)",
    "Норма"))
  ) AS "Директивное предписание"
FROM #инвариант AND "Карточки"
WHERE !id OR !статус OR !дата OR статус = "на_пересмотре" OR (date(today) - date(дата)).days > 14
SORT file.name ASC
```

## 2. Действующий реестр инвариантов конвейера

```dataview
TABLE WITHOUT ID
  file.link AS "Инвариант",
  id AS "ID",
  статус AS "Статус",
  дата AS "Дата ревизии",
  (date(today) - date(дата)).days AS "Дней с ревизии"
FROM #инвариант AND "Карточки"
SORT file.name ASC
```
