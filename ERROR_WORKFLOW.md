# Протокол обработки ошибок и сбоев (ERROR_WORKFLOW)

## 1. Звуковая индикация macOS
* Успешное завершение критических блоков и синхронизаций:
  `afplay /System/Library/Sounds/Pop.aiff`
* Фиксация сбоя, откат или нарушение контрольного барьера:
  `afplay /System/Library/Sounds/Basso.aiff`

## 2. Logging First
* Любая ошибка выполнения сначала полностью логируется с указанием контекста, времени и кода возврата.
* Запрещено предпринимать корректирующие действия в контуре до внесения записи об инциденте в журнал.

## 3. Remote Guard Barrier
* Завершение любой итерации требует выполнения `git push`.
* Сессия признается стабильной только после подтверждения паритета локальной ветки `main` и ветки `origin/main`.
* При обнаружении расхождения веток дальнейшие изменения блокируются до восстановления полного синхронного состояния.
