# Стандарт безопасного транспорта и CLI

## 1. Базовые принципы терминала (zsh)
* Каждая команда терминала передается строго отдельным блоком.
* Запрещены цепочки команд через операторы `&&`, `||`, `;`.
* Любая запись и модификация содержимого файлов осуществляется исключительно через конструкцию `cat << 'EOF' > путь/к/файлу`. Кавычки вокруг ограничителя `'EOF'` строго обязательны для предотвращения нежелательной интерполяции переменных оболочки.
* Запрещено выполнение кода через `python3 -c "..."`. Все скрипты оформляются в виде отдельных исполняемых файлов.

## 2. Изоляция и пути
* Все пути к файлам и каталогам с пробелами или специальными символами должны оборачиваться в двойные кавычки.
* Команды выполняются строго относительно корня текущего активного контура репозитория.
