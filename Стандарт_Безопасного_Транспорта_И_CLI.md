## 1. Запрещенные паттерны терминала (Антипаттерны)

В контуре взаимодействия терминала и скриптов действуют жесткие ограничения:

1. **Запрет на вложенный `python3 -c`:**
   Категорически запрещено передавать многострочный Python-код через аргумент командной строки (`python3 -c '...'`). Кавычки внутри скрипта (одинарные, двойные, AppleScript) неизбежно вызывают синтаксический сбой `zsh: parse error near '}'`.
2. **Запрет на вставку сырого Markdown в Prompt:**
   Запрещено вставлять неподготовленный текст, карточки или Frontmatter напрямую в интерактивное приглашение `zsh`. Обратные кавычки (backticks ````) переводят оболочку в аварийный режим ожидания `bquote>`, а строки frontmatter исполняются как неизвестные команды (код 127).
3. **Запрет на «мета-генерацию» кода через shell:**
   Не создавать скрипты, которые внутри shell вызывают утилиты `write_text` для генерации других скриптов.

## 2. Стандарт создания и обновления файлов через терминал

### А. Принцип атомарности: «Один файл — одна команда»
Создание новых файлов и их полная архитектурная перезапись производятся **строго изолированно**:
- Запрещено склеивать создание нескольких файлов в одну монолитную shell-команду через `&&` или `;`.
- Каждый файл генерируется отдельной командой через конструкцию `cat << 'EOF'`:

```bash
cat << 'EOF' > "путь/к/файлу.py"
# Чистый код или разметка
# Кавычки 'EOF' в одинарных кавычках отключают парсинг zsh
