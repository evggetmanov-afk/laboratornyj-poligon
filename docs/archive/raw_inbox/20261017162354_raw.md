# Реализация браузерного шлюза через Tampermonkey

## Компоненты окружения
1. **Stylebot / uBlock Origin:** Косметическая очистка интерфейса от блоков интерактивных подсказок и рекомендаций:
   ```css
   suggestion-chip,
   follow-up-suggestions,
   elicitations-container,
   div[class*="suggestion-container"],
   div[class*="follow-up"] {
     display: none !important;
   }
   ```
2. **Tampermonkey (UserScript):** Управление фоновым окном и передача данных.

## Жизненный цикл фонового воркера

```
[Основное окно: парсинг DOM] 
       │ Находит блок "### TASK_PAYLOAD"
       │ Встраивает кнопку "🚀 Запустить в воркере"
       ▼ (клик оператора)
[GM_setValue('worker_task', text)]
       │
       ▼
[GM_openInTab('[https://gemini.google.com/app?worker=1](https://gemini.google.com/app?worker=1)', { active: false })]
       │
       ▼ (Фоновая вкладка)
1. Считывает GM_getValue('worker_task')
2. Вставляет текст в contenteditable через document.execCommand('insertText')
3. Инициирует клик по send-button
4. Ожидает возврата кнопки в ненажатое состояние (генерация окончена)
5. Извлекает innerText последнего ответа
6. Записывает в буфер через GM_setClipboard
7. Закрывает себя через window.close()
```
