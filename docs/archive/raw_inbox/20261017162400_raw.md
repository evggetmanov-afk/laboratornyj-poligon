# Дорожная карта эволюции контура

## Фаза 1: Браузерный прототип (Трение: Низкое / Затраты: Минимальные)
- **Инструменты:** Tampermonkey, Stylebot.
- **Цель:** Обкатка формата `TASK_PAYLOAD`, отладка мысленной песочницы у LLM.
- **Критерий завершения фазы:** Формулировки промпта дают детерминированный результат в 9 из 10 запусков; выявлены типовые размеры задач.

## Фаза 2: Локальный API-воркер (Трение: Нулевое / Стабильность: Абсолютная)
- **Инструменты:** Python (`google-genai`), Raycast / Zsh alias, системный буфер обмена (`pbcopy` / `pbpaste`).
- **Схема работы:**
  1. Оператор копирует `TASK_PAYLOAD` в основном чате (`Cmd + C`).
  2. Нажимает локальный шорткат в Raycast / macOS.
  3. Скрипт `worker.py` в фоне обращается к Gemini API.
  4. Результат автоматически валидируется и перезаписывает буфер обмена.
  5. Всплывает нативное системное уведомление macOS.
- **Преимущества перехода:** Полная независимость от изменений верстки Google, отсутствие лишних вкладок в памяти браузера, задержка ответа 2–4 секунды.
