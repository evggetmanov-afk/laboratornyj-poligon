title: "Подключение по CDP (Chrome DevTools"
---

Подключение по CDP (Chrome DevTools Protocol) действительно привязано к браузерам на базе движка Chromium (Google Chrome, Brave, Edge, Arc). Однако в нативном десктопном приложении Gemini это **тоже реализуемо**, если учесть техническое устройство самого приложения.

Существуют два сценария в зависимости от того, как именно установлено приложение Gemini:

---

### 1. Если нативное приложение — это PWA (Progressive Web App)

Подавляющее большинство пользователей устанавливают «нативное» Gemini через кнопку в браузере (*«Установить приложение Gemini»*).

* Технически это не отдельная независимая программа, а легковесный контейнер того же Chrome без адресной строки.
* **Как подключить Playwright:** Такое окно по-прежнему управляется основным процессом Chrome. Если Chrome изначально запущен с флагом `--remote-debugging-port=9222`, открытое окно PWA отображается в списке страниц (`browser.contexts[0].pages`) на том же порту, и Playwright спокойно считывает из него DOM.

---

### 2. Если нативное приложение собрано на Electron

Официальные десктопные клиенты подобных сервисов под macOS (как и Slack, Discord, Notion или VS Code) строятся на базе фреймворка **Electron**, который внутри представляет собой упакованный Chromium.

* У любого Electron-приложения есть встроенная поддержка того же отладочного порта CDP.
* **Как подключить:** Достаточно запустить само приложение Gemini через Терминал с аналогичным ключом:
```bash
/Applications/Gemini.app/Contents/MacOS/Gemini --remote-debugging-port=9222

```


После этого Playwright подключается к нему точно так же, как к обычному браузеру.

---

### Альтернатива без CDP: Системная доступность macOS (Accessibility API)

Если приложение Gemini полностью закрыто от сетевых портов отладки, задачу чтения текста решают через системный интерфейс доступности macOS (**Apple Accessibility API**), не трогая буфер обмена:

* **Библиотека:** `pyobjc` (модуль `ApplicationServices` / `AXUIElement`).
* **Принцип:** Скрипт находит окно процесса `Gemini` на уровне операционной системы, опрашивает дерево элементов интерфейса (Accessibility Tree) и извлекает атрибут `AXValue` (текст) из последнего текстового поля окна.
* **Результат:** Текст забирается программно из любого нативного приложения без `Cmd+C` и без эмуляции браузера.
