# ПРОТОКОЛ ЗАПИСИ АРТЕФАКТОВ (PAYLOAD INVARIANT)

## 1. Штатный контур (L0: Python / save_clip.py)
- Любой файл, создаваемый или модифицируемый моделью, отдается РОВНО ОДНИМ монолитным блоком.
- Первая строка блока СТРОГО: `### FILE: <относительный_путь_от_корня>`.
- Под блоком файла разрешено размещать ТОЛЬКО пассивную рамку-напоминание (Markdown-цитату `>`):
  `> Используйте алиас save в терминале.`
- КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО создавать отдельные блоки кода с терминальными командами (`bash / save`), так как интерфейс добавляет к ним кнопку копирования, что приводит к затиранию буфера.
- Оператор нажимает «Скопировать» на блоке файла в чате.
- В терминале вручную вызывается ровно одна команда без аргументов: `save`.
- Скрипт `scripts/save_clip.py` извлекает путь, отсекает первую строку, создает директории и сохраняет файл в UTF-8 с тройным подтверждением (звук, терминал, macOS-нотификация).

## 2. Запрещенные паттерны вывода
- ЗАПРЕЩЕНО использовать `cat << 'EOF'`, интерактивные редакторы (`nano`/`vim`) и ручную вставку через Cmd+V.
- ЗАПРЕЩЕНО передавать целевой путь аргументом командной строки (`save <путь>`).
- ЗАПРЕЩЕНО требовать от оператора копирования команд терминала во время нахождения полезной нагрузки в буфере.

## 3. Аварийный контур (L1: POSIX / fsave)
В случае сбоя Python-окружения активируется резервная функция `fsave` в `~/.zshrc`:
- Работает на нативных `pbpaste` и `sed` без сторонних библиотек.
- Вызывается строго вручную с клавиатуры: `fsave`.

## 4. Критический сброс (L2: Сырой дамп)
При повреждении структуры заголовка буфер сбрасывается в зафиксированную точку:
`pbpaste > .swap/raw_clip.txt`
