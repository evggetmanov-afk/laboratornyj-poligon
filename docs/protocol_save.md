# ПРОТОКОЛ ЗАПИСИ АРТЕФАКТОВ (PAYLOAD INVARIANT)

## 1. Единственный формат генерации файлов моделью
Любой файл, создаваемый или модифицируемый моделью для переноса на диск, обязан выдаваться в чате отдельным блоком, где первая строка имеет строго следующий синтаксис:

### FILE: <относительный_путь_от_корня>

После этой строки без дополнительных пустых строк идет чистое содержимое файла.
Завершающие маркеры не требуются.

## 2. Запрещенные паттерны вывода
- ЗАПРЕЩЕНО оборачивать код файла в синтаксические блоки Markdown типа ```python или ```bash, если они не являются частью самого файла.
- ЗАПРЕЩЕНО указывать имя целевого файла в терминальной команде (например, `save path/to/file` или `python3 scripts/save_clip.py path/to/file`).
- ЗАПРЕЩЕНО выдавать команду терминала перед или после блока файла, если это требует повторного копирования из чата.

## 3. Терминальный вызов
Оператор нажимает кнопку копирования на блоке файла и в терминале выполняет ровно одну команду:
save
