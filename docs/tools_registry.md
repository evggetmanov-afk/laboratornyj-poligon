# Реестр инструментов Лабораторного полигона

Документ фиксирует служебные скрипты ядра и проектных модулей, их назначение и синтаксис вызова.

---

## 1. Системные скрипты ядра (Контур 1 / scripts/)

| Скрипт | Назначение | Команда вызова |
|---|---|---|
| `scripts/save_clip.py` | Запись содержимого буфера macOS в файл по маркеру `### FILE: <путь>` | `save` (системный алиас) |
| `scripts/apply_payload.py` | Пакетная распаковка многофайлового буфера в репозиторий | `pbpaste \| python3 scripts/apply_payload.py` |
| `scripts/vahta.py` | Контроль вахты, фиксация сдачи смены и генерация отчетов | `python3 scripts/vahta.py status` / `close` |

---

## 2. Проектные инструменты: Strategy Engine (projects/strategy_engine/src/)

| Скрипт | Контур | Назначение | Синтаксис запуска |
|---|---|---|---|
| `planner.py` | Контур А | Генерация детерминированной карточки стратегии с автоинкрементом ID | `python3 projects/strategy_engine/src/planner.py --goal "Цель" --title "Имя"` |
| `runner.py` | Контур С | Механический запуск команд `CMD:` из карточки стратегии с автоподхватом свежей | `python3 projects/strategy_engine/src/runner.py [путь_к_карточке]` / `strat` |
