# Реестр инструментов ядра (Tools Registry)

## 1. vahta.py
- **Назначение:** Управление жизненным циклом вахты, фиксация отчетов в `watch_log/` и передача эстафеты контекста между сессиями диалога.
- **Путь:** `scripts/vahta.py`
- **Вызов:**
  - `python3 scripts/vahta.py open` — открыть смену, сформировать контекст для нового чата.
  - `python3 scripts/vahta.py close` — закрыть смену, сохранить отчет в `watch_log/` и подготовить Git-коммит.
- **Грабли и ограничения:** Не запускать закрытие без предварительной фиксации результатов в `.swap/TASK.md`.

## 2. apply_payload.py
- **Назначение:** Детерминированная распаковка файлов из текста диалога байт-в-байт с автоматическим созданием подкаталогов.
- **Путь:** `scripts/apply_payload.py`
- **Вызов:** `python3 scripts/apply_payload.py` (читает `.swap/TASK.md`) или `python3 scripts/apply_payload.py <путь_к_файлу>`.
- **Грабли и ограничения:** Не принимает ввод через пайп (`stdin`). Работает только через промежуточный файл задачи.
