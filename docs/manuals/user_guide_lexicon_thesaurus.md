# Инструкция пользователя: Семантический слой и Тезаурус (ADR-004)

Практическое руководство по использованию онтологического контура «Лабораторного полигона» и проекта «Tennis Blitz».

---

## 1. Назначение и Архитектурный принцип
Семантический слой решает задачу устранения смыслового дрейфа между оператором, скриптами автоматизации и внешними LLM-агентами.

Главные правила архитектуры:
1. **Атомарность:** Каждое понятие хранится строго в отдельном Markdown-файле в папке `docs/thesaurus/` с жестким YAML-заголовком. Монолитных файлов для записи нет.
2. **Двухфазный контур:**
   - *Фаза 1 (Быстрый инжест):* Прием сырья в `00_raw_inbox/` идет мгновенно скриптами без вызова нейросетей.
   - *Фаза 2 (Семантизация):* Проверка готовых документов запускается оператором осознанно по требованию (On-Demand).
3. **Двухслойный маппинг:** В каждой карточке честная физика биомеханики/системы отделена от клиентского презентационного фасада (`presentation_mapping`).
4. **Инвариант отрицания:** Блок «НЕ является» задает жесткие рамки, отсекая галлюцинации языковых моделей.
