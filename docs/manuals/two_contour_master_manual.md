# Регламент оператора двухконтурного мастера

## 1. Назначение и контуры системы
Регламент определяет строгий порядок работы оператора при взаимодействии с языковой моделью через браузер, буфер обмена macOS и физический пульт управления.

Система разделена на два изолированных контура:
* **Контур 1 (Рабочее ядро на SSD):** код, правила, инструменты ядра, чистый Markdown под контролем Git. Вносить тяжелые файлы запрещено.
* **Контур 2 (Операционный цикл на Google Диске):** прием сырья, видео, тяжелые базы, архивы. Находится строго вне репозитория ядра.

Связь между контурами идет исключительно через шлюзы `inbox/` (вход) и `ready/` (выход).

## 2. Аппаратный и программный стек
1. **Интерфейс диалога:** веб-сессия Gemini в браузере.
2. **Tampermonkey:** скрипт браузера, добавляющий кнопку мгновенного копирования целевого артефакта с маркером `### FILE:` в системный буфер macOS без захвата лишней разметки интерфейса.
3. **Системный буфер обмена macOS:** изолированный транспорт между браузером и терминалом.
4. **Утилита save (scripts/save_clip.py):** локальный обработчик буфера, проверяющий валидность пути и выполняющий атомарную запись на диск.
5. **Elgato Stream Deck:** физический контроллер на рабочем столе для вызова базовых операций одним нажатием клавиши.

## 3. Протокол сохранения артефактов (Стандарт Clipboard Stream)

### Стандартный цикл записи файла
1. Модель формулирует содержимое файла, предваряя его служебным маркером `### FILE: <относительный_путь>`.
2. Оператор нажимает кнопку скрипта Tampermonkey в браузере (или копирует блок с маркером). Содержимое попадает в системный буфер macOS.
3. Оператор нажимает физическую клавишу `SAVE` на Stream Deck (или выполняет команду `save` в терминале).
4. Утилита `save_clip.py` считывает буфер, находит маркер, создает недостающие родительские каталоги и перезаписывает файл на SSD.
5. Оператор подтверждает успешную запись модели в чате.

### Запрещенные действия
* Запрещено копировать текст вручную через Cmd+V в открытый терминал.
* Запрещено применять конструкции потокового ввода Heredoc (`cat << 'EOF'`).
* Запрещено подтверждать сохранение файла модели до фактического срабатывания утилиты `save`.

## 4. Конфигурация клавиш Elgato Stream Deck
* **Кнопка 1 [SAVE]:** запуск команды `save` (вызов `python3 scripts/save_clip.py`).
* **Кнопка 2 [DIFF]:** быстрый осмотр изменений (`git diff`).
* **Кнопка 3 [STATUS]:** проверка состояния рабочей копии (`git status -s`).
* **Кнопка 4 [PAYLOAD]:** пакетная распаковка из буфера (`pbpaste | python3 scripts/apply_payload.py`).
* **Кнопка 5 [VAHTA STAT]:** просмотр текущего контракта (`python3 scripts/vahta.py status`).
* **Кнопка 6 [VAHTA CLOSE]:** завершение смены и фиксация лога (`python3 scripts/vahta.py close`).

## 5. Порядок сдачи смены
1. Проверить выполнение всех пунктов из `.swap/TASK.md`.
2. Нажать клавишу `STATUS` на Stream Deck и убедиться, что изменены только файлы из скоупа.
3. Нажать клавишу `VAHTA CLOSE` на Stream Deck (или выполнить `python3 scripts/vahta.py close` в терминале).
4. Отправить в чат команду «Сдать смену».
