# Руководство оператора: Knowledge Pipeline и оформление схем

## 1. НАЗНАЧЕНИЕ
Руководство по обработке заметок в конвейере знаний, протоколу безопасного сохранения через системный буфер и проектированию графических диаграмм с помощью роли `/схема`.

---

## 2. ПРОТОКОЛ СОХРАНЕНИЯ МАТЕРИАЛОВ (Clipboard Stream)
1. **Подготовка файла в диалоге:**
   - Модель формирует блок с первой строкой вида:
     ```text
     ### FILE: <относительный_путь>
     ```
2. **Перенос на SSD:**
   - Скопировать блок содержимого в буфер обмена кнопкой чата.
   - В терминале выполнить системную команду:
     ```bash
     save
     ```
   - Запрещено использовать ручную вставку многострочного текста (`Cmd+V`) и `cat << EOF` прямо в терминал.
3. **Фиксация и архивация:**
   - Проверить статус Git:
     ```bash
     git status -s
     ```
   - Зафиксировать изменения коммитом:
     ```bash
     git add docs/ && git commit -m "docs: add verified notes"
     ```
   - Исходный сырой файл из инбокса перенести в архив на Google Диске (правило No-Delete: физическое удаление без архивации запрещено).
