# Инструкция оператора: Конвейер заметок и Мастер графических схем

Руководство по обработке входящих материалов, созданию атомарных заметок и визуализации архитектурных процессов через Mermaid.

---

## 1. РАЗДЕЛЕНИЕ КОНТУРОВ
Оператор работает строго по принципу двух контуров:
- **Контур 2 (Google Диск):** Приемник тяжелых файлов, дампов браузера, логов и сырых аудио/видео. Исключает разрастание Git-репозитория на локальном SSD.
- **Контур 1 (SSD MacBook / Репозиторий):** Рабочий верстак. Содержит только чистые скрипты, спецификации и Markdown-карточки под контролем Git.

---

## 2. ШАГИ ОБРАБОТКИ СЫРЬЯ (Knowledge Pipeline)

1. **Захват сырья:**
   - Поместить входящий текст или веб-клип в шлюз инбокса (`00_raw_inbox/` или внешний `kp_inbox/`).
   - Убедиться, что имя файла содержит временную метку `YYYYMMDDHHMMSS_raw <название>.md`.

2. **Экстракция сути:**
   - Открыть сессию полигона с моделью.
   - Запросить выделение ключевых тезисов, инвариантов и архитектурных решений (формат ABC / ADR).
   - При обнаружении дампов, дубликатов или мусора — изолировать их в `_quarantine/` (тяжелые архивы — вынести в Контур 2).

3. **Запись в ядро (Clipboard Stream):**
   - Модель готовит блок с маркером `### FILE: docs/...`.
   - Нажать кнопку копирования блока в чате.
   - В терминале выполнить системную команду:
     ```bash
     save
     ```
   - Запрещено использовать ручную вставку многострочного текста (`Cmd+V`) и `cat << EOF` прямо в терминал.

4. **Фиксация и архивация:**
   - Проверить статус Git:
     ```bash
     git status -s
     ```
   - Зафиксировать изменения коммитом:
     ```bash
     git add docs/ && git commit -m "docs: add verified notes"
     ```
   - Исходный сырой файл из инбокса перенести в архив на Google Диске (правило No-Delete: физическое удаление без архивации запрещено).
