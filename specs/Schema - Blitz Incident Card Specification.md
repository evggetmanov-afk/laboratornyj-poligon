# Спецификация: Схема карточки инцидента «Блиц» (Blitz Incident Card)

## 1. Назначение и архитектурные принципы

Спецификация определяет структуру единичной карточки розыгрыша (инцидента) при циклическом разборе матча (100+ повторений за сессию).

* **Отказ от бумажного протокола:** Исключена ручная аббревиатурная стенография. Структура ориентирована на прямое чтение мультимодальными LLM и Dataview-индексацию.
* **Принцип Schemaless / Data-First:** Первичен объективный след реальности. Карточка является устойчивым контейнером для:
  1. Метаданных счета и видеоисточника.
  2. Дискретных номеров кадров (FN в множестве N) и стоп-кадров ключевых контактов.
  3. Непрерывного транскрипта экспертной речи тренера (Think Aloud).
* **Ретроспективная расширяемость:** Дополнительные тактические параметры и метрики извлекаются нейросетью из накопленного пула карточек без изменения базовой структуры схемы.

Ключевые поля карточки инцидента:

- фаза: блиц_4_удара
- матч_id: WTA_YYYY_ТУРНИР_ИГРОК1_ИГРОК2
- счет: "30:15"
- сет: 1

### 3.2. Автоматическая телеметрия (Физика эпизода)

Формулы вычисляются скриптом или Dataview-индексом:
* **Время полета мяча при подаче:** t_подачи = (FN_2 - FN_1) / FPS (сек)
* **Время на реакцию и подготовку приема:** t_приема = (FN_3 - FN_2) / FPS (сек)
* **Темп завязки комбинации (Подача -> 3-й удар):** t_темп = (FN_4 - FN_1) / FPS (сек)

### 3.3. Экспертный след: Протокол «Think Aloud»

Свободная надиктовка тренера во время просмотра и прокрутки эпизода шаттлом. Транскрибируется через локальный Whisper:

> [!quote] Голосовой протокол тренера (Think Aloud)
> «Счет 30:15, на подаче Соболенко. Занимает острую оппозицию, встречает строго на задней линии, не отваливается назад. Ждет мяч под лево. Пошла плотная косая во второй квадрат. Принимающая играет блок с полулета по линии. Подающая не успевает стабилизировать стопы после приземления и на 3-м ударе бьет в противоход из динамической нестабильности...»

### 3.4. Служебный блок FFMPEG-нарезки (Deliverable игроку)

Параметры для мгновенной пакетной сборки 3–5 секундного клипа:
* **Интервал нарезки:** [FN_0 - offset, FN_5 + offset]
* **Тематический тег плейлиста:** #clip/serve_wide_box2, #clip/opposition_aggressive

- [ ] Голосовой транскрипт зафиксирован без редакторских сокращений.
