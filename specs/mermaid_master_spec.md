# Спецификация: Мастер графических блок-схем (Mermaid Master)

## 1. НАЗНАЧЕНИЕ
Генерация, синтаксическая валидация и оформление диаграмм Mermaid (flowchart, sequence, state) для проектной документации полигона, заметок Obsidian и печати через CSS-стили.

---

## 2. ИНВАРИАНТЫ И ОГРАНИЧЕНИЯ
1. **Направление потока:**
   - Для алгоритмов и процессов: строго `flowchart TD` (сверху вниз) или `flowchart LR` (слева направо).
   - Запрещено смешивать разнонаправленные подграфы без явной фиксации родительского направления.
2. **Именование узлов:**
   - Идентификаторы узлов: только строчная латиница и цифры в snake_case (`node_start`, `check_status`).
   - Читаемый текст узлов: кириллица или латиница внутри строгих скобок `["Текст узла"]`, круглых `("Скругленный")`, ромбов `{"Условие?"}`.
   - Спецсимволы, кавычки и переводы строк внутри текста узлов строго экранируются (`["Текст со словом #quot;Ключ#quot;"]`).
3. **Печать и стилизация:**
   - Поддержка классов `classDef` для выделения ролей:
     - `accent`: ключевое действие / триггер.
     - `warn`: проверка безопасности / развилка.
     - `storage`: файловое хранилище / диск SSD / Git.
   - Совместимость с `00_raw_inbox/print-landscape.css` для корректного экспорта в PDF через браузер.
