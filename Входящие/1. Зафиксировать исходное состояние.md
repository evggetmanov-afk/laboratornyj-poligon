# 1. Зафиксировать исходное состояние

1. **Зафиксировать исходное состояние**
* Сделать полную копию всей папки с проектом.
* Сформировать плоский список всех существующих файлов и директорий.
* Отложить любые изменения до создания резервной копии.


2. **Разделить зоны ответственности**
* Выделить отдельную папку для исходных неизменяемых материалов.
* Собрать все рабочие сценарии и инструменты в единый каталог.
* Вынести шаблоны запросов и настройки отдельно от программного кода.
* Назначить строго одно место для сохранения готовых результатов.
* Создать изолированную временную папку для черновиков и тестов.


3. **Описать правила структуры в одном файле**
* Создать текстовый документ с описанием каркаса проекта в корневой папке.
* Закрепить назначение каждой базовой директории.
* Установить единый стандарт для названий файлов.
* Запретить автоматическое создание новых папок без предварительного согласования.


4. **Провести поэтапную чистку**
* Перенести все подозрительные файлы и дубликаты в папку карантина.
* Запустить основные рабочие процессы для проверки их работоспособности.
* Вернуть на место только те элементы, отсутствие которых вызвало сбой.
* Удалить содержимое карантина через заданный срок.


5. **Ограничить действия модели**
* Передавать модели правила структуры перед началом каждой новой задачи.
* Требовать изменение существующих файлов вместо создания новых копий.
* Проверять новые решения во временной папке перед переносом в основную систему.
