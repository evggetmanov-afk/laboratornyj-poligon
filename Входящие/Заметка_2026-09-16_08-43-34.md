# ПРАВИЛА РАБОТЫ С ФАЙЛАМИ И ТЕРМИНАЛОМ (BASH / ZSH)
1. ЗАПРЕТ НА ВЛОЖЕННЫЙ EVAL:
   - Категорически запрещено использовать `python3 -c "..."`, `node -e "..."` или `bash -c "..."` для генерации или редактирования файлов на диске. Это приводит к синтаксическим ошибкам экранирования кавычек в zsh.
   
2. СТАНДАРТ СОЗДАНИЯ И ПЕРЕЗАПИСИ ФАЙЛОВ:
   - Если нужно записать код в файл через shell, ВСЕГДА используй ТОЛЬКО конструкцию Heredoc с экранированным маркером в одинарных кавычках:
     cat << 'EOF' > /путь/к/файлу.ext
     [содержимое файла в чистом виде]
     EOF
   - Кавычки вокруг 'EOF' обязательны: они отключают интерполяцию переменных и экранирование.

3. ПРЯМОЙ ВЫВОД:
   - Не создавай «скриптов, которые с помощью библиотек пишут другие скрипты». Записывай целевой файл сразу.
