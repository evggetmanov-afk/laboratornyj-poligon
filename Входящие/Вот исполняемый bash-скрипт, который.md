# Вот исполняемый bash-скрипт, который

Вот исполняемый bash-скрипт, который обновляет нативные документы (добавляет концепт **Адресного указателя смыслов / Semantic Pointer** в базу знаний, реестр и корневой манифест) и разворачивает CLI-утилиту `.swap/bin/ptr` для мгновенной навигации.

Выполните блок целиком в терминале вашего репозитория:

```bash
# 1. Создаем каталог под утилиты
mkdir -p .swap/bin

# 2. Добавляем карточку B4 и термин в .swap/docs/abc_vault.md
cat << 'EOF' >> .swap/docs/abc_vault.md

### [B4] Адресный указатель смыслов (Semantic Pointer)
- **Суть:** Разделение легковесного оперативного реестра и тяжелого хранилища знаний.
- **Принцип:** В рабочей зоне хранятся только карточки-указатели (ID, 1 строка сути, точный URI/якорь). Полный текст живет в архиве/NotebookLM.
- **Эффект:** Нулевой поиск. Модель и оператор обращаются к сущностям по точным меткам без сканирования всей базы.
EOF

# Добавляем определение в блок тезауруса abc_vault.md
cat << 'EOF' >> .swap/docs/abc_vault.md

### Адресный указатель (Semantic Pointer)
Легковесная структура данных, связывающая идентификатор атома, его однострочную сигнатуру и точный физический адрес в хранилище (локальном файле или внешнем блокноте).
EOF

# 3. Обновляем .swap/INDEX.md актуализированным реестром с адресами
cat << 'EOF' > .swap/INDEX.md
# КЛЮЧ К СИСТЕМЕ (SYSTEM INDEX & REGISTRY)

## 1. ВНЕШНИЕ СВЯЗИ
- NotebookLM Vault: https://notebooklm.google.com/
- Git-репозиторий: laboratornyj-poligon (branch: main)
- Локальная база карточек: .swap/docs/abc_vault.md

## 2. РЕЕСТР АТОМАРНЫХ КАРТОЧЕК (СЕМАНТИЧЕСКИЕ УКАЗАТЕЛИ)
| ID | Уровень | Суть атома (Сигнатура) | Физический адрес |
| :--- | :--- | :--- | :--- |
| A1 | Смысл | Запрет на ручной перенос контекста | `.swap/docs/abc_vault.md#a1` |
| A2 | Смысл | Дерево целей человека — шум для LLM | `.swap/docs/abc_vault.md#a2` |
| A3 | Смысл | Разделение мышления и исполнения | `.swap/docs/abc_vault.md#a3` |
| B1 | Механика | Диск как единственный канал связи | `.swap/docs/abc_vault.md#b1` |
| B2 | Механика | 4-фазный жизненный цикл кванта | `.swap/docs/abc_vault.md#b2` |
| B3 | Механика | Приемка по падающему/зеленому тесту | `.swap/docs/abc_vault.md#b3` |
| B4 | Механика | Адресный указатель смыслов | `.swap/docs/abc_vault.md#b4` |
| C1 | Контракт | Спека файла .swap/TASK.md | `.swap/TASK.md` |
| C2 | Контракт | Инварианты манифеста A_FRAME.md | `.swap/A_FRAME.md` |
| C3 | Контракт | Git-шлюз фиксации квантов | `.swap/docs/abc_vault.md#c3` |

## 3. БЫСТРЫЙ ТЕЗАУРУС
- **Атомарная сессия:** Одноразовый stateless-исполнитель.
- **Квант работы:** Неделимая единица задачи с проверяемым тестом.
- **Файл подкачки:** Буфер на диске (.swap/TASK.md).
- **Инвариант:** Неизменяемое архитектурное правило/табу.
- **Семантический дрейф:** Искажение сути при пересказе диалога.
- **Semantic Pointer:** Связка «ID — Суть — Физический адрес».

## 4. ДИРЕКТИВЫ ЗАПУСКА ДЛЯ ЧАТОВ
- **Для сессии осмысления:** «Работай по методологии A-B-C. Изучи .swap/INDEX.md, сформируй контракт кванта в .swap/TASK.md».
- **Для сессии исполнения:** «Читай .swap/TASK.md. Изменяй только файлы из СКОУПА. Проверь результат по КРИТЕРИЮ ПРИЕМКИ. Заполни СТАТУС».
EOF

# 4. Обновляем корневой README.md упоминанием реестра указателей
cat << 'EOF' > README.md
# Лабораторный полигон

Репозиторий для отработки архитектурных гипотез, протоколов и инженерных пайплайнов.

## Регламент взаимодействия (A-B-C Protocol)
Работа с контекстом и задачами ведется через файл подкачки и адресный указатель без ручного переноса логов.
- **Точка входа и Реестр указателей:** `.swap/INDEX.md`
- **Инварианты и рамка:** `.swap/A_FRAME.md`
- **Текущий квант работы:** `.swap/TASK.md`
- **База знаний и тезаурус:** `.swap/docs/abc_vault.md`
- **CLI-навигатор:** `.swap/bin/ptr`
EOF

# 5. Создаем CLI-скрипт .swap/bin/ptr
cat << 'EOF' > .swap/bin/ptr
#!/usr/bin/env bash

SWAP_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
INDEX_FILE="$SWAP_DIR/INDEX.md"
VAULT_FILE="$SWAP_DIR/docs/abc_vault.md"

case "$1" in
  list)
    # Показать таблицу карточек из реестра
    awk '/## 2. РЕЕСТР/,/## 3. БЫСТРЫЙ/' "$INDEX_FILE" | grep -E '^\|'
    ;;
  open)
    # Открыть URL блокнота NotebookLM в браузере по умолчанию
    URL=$(grep -m 1 "NotebookLM Vault:" "$INDEX_FILE" | awk '{print $3}')
    if [[ "$URL" =~ ^https?:// ]]; then
      open "$URL"
      echo "Открываю блокнот: $URL"
    else
      echo "Ошибка: в $INDEX_FILE не указан валидный URL NotebookLM."
    fi
    ;;
  copy)
    # Скопировать блок карточки по ID в буфер обмена macOS
    ID="$2"
    if [ -z "$ID" ]; then
      echo "Использование: ptr copy [ID] (например: ptr copy B4)"
      exit 1
    fi
    awk -v id="[$ID]" '
      $0 ~ "### " id {flag=1; print; next}
      flag && /^### / {flag=0}
      flag && /^---/ {flag=0}
      flag {print}
    ' "$VAULT_FILE" | pbcopy
    echo "Карточка [$ID] скопирована в буфер обмена."
    ;;
  task)
    # Показать текущий файл подкачки
    cat "$SWAP_DIR/TASK.md"
    ;;
  *)
    echo "Использование: .swap/bin/ptr {list|open|copy <ID>|task}"
    echo "  list       - Вывести реестр атомов и адресов"
    echo "  open       - Открыть связанный блокнот NotebookLM в браузере"
    echo "  copy <ID>  - Скопировать карточку в буфер обмена (напр., ptr copy B4)"
    echo "  task       - Вывести текущую задачу из файла подкачки"
    ;;
esac
EOF

# 6. Даем права на исполнение утилите
chmod +x .swap/bin/ptr

# 7. Фиксация в Git и отправка на GitHub
git add .swap/ README.md
git commit -m "feat: добавлен паттерн Semantic Pointer, реестр адресов и CLI-утилита ptr"
git push

```

### Как пользоваться новой утилитой:

После применения скрипта в терминале доступны быстрые команды:

* `.swap/bin/ptr list` — мгновенно печатает таблицу всех карточек, их суть и пути.
* `.swap/bin/ptr copy B4` — находит карточку `[B4]` в базе и копирует её прямо в буфер обмена macOS (через `pbcopy`).
* `.swap/bin/ptr open` — открывает ссылку на NotebookLM из первой строчки реестра в браузере.
* `.swap/bin/ptr task` — выводит текущее задание из `.swap/TASK.md`.
