# Лабораторный полигон

Локальное автономное Obsidian-хранилище для практического тестирования возможностей LLM в ролях системного архитектора, инженера автоматизации и контент-редактора.

---

## 1. Архитектура хранилища
- `Входящие/` — точка сброса необработанных заметок, сниппетов и контекстов.
- `Источники/` — исходные немодифицируемые материалы, логи сессий, стенограммы.
- `Карточки/` — атомарная база знаний по принципу Zettelkasten (один тезис — одна заметка, связь через `[[WikiLinks]]`).
- `Вахтенный_журнал/` — хроника системных изменений, аудита и ежедневных логов.
- `Система/` — шаблоны (`Шаблоны/`) и системные регламенты/промпты (`Промпты/`).
- `.system/` — скрытая инфраструктурная директория (скрипты, виртуальные окружения). Полностью игнорируется поиском и графом Obsidian.

---

## 2. Стандарты метаданных (Frontmatter)
Каждая карточка содержит обязательный блок YAML:
```yaml
---
дата: ГГГГ-ММ-ДД
тип: атомарная | источник | дашборд | журнал
статус: сырое | обработано | проверено
агент: человек | gemini | aider
источники: []
теги: []
---
```

---

## 3. Регламент автоматизации и скриптов (Raycast First)
1. **Приоритет интерфейса:** Все триггеры, горячие клавиши и захват данных строятся через **Raycast** (Script Commands). Сторонние утилиты подключаются только при технической невозможности решения в Raycast.
2. **Изоляция скриптов (Двухуровневая модель):**
   - **Ядро (`.system/scripts/`):** Исполняемая бизнес-логика (парсинг, атомизация, запись в журнал). Версионируется в Git репозитория полигона. Имя папки начинается с точки, поэтому Obsidian исключает ее из индексов.
   - **Тонкие клиенты Raycast (`~/.config/raycast/scripts/polygon/`):** Обертки с метаданными Raycast, вызывающие ядро. Изолированы от хранилища, не ломаются при рефакторинге заметок.
3. **Регламент отказоустойчивости терминала:**
   - Каждая составная команда начинается с очистки экрана `clear &&`.
   - Инструкции и ожидаемый результат размещаются строго до кодового блока.
   - Правило трех попыток: при ошибке сразу выдается исправление; после 3 сбоев процесс останавливается для анализа.
