# Лабораторный полигон

Рабочий репозиторий для изоляции, тестирования регламентов и отработки инструментов автоматизации.

## Архитектурные регламенты
* `Стандарт_Безопасного_Транспорта_И_CLI.md` — регламент взаимодействия с zsh, экранирование heredoc и ограничения CLI.
* `ERROR_WORKFLOW.md` — системный протокол логирования ошибок, звуковая телеметрия macOS и Remote Guard.
* `Система/Промпты/Системный_Контракт.md` — консолидированный контракт взаимодействия и архитектурные правила.

## Структура архива
* `Архив/Регламенты_Архив/` — исторические версии регламентов и контрактов.
