# Лабораторный полигон

Рабочее пространство автоматизации, инженерных регламентов взаимодействия с LLM и ведения вахтенного журнала.

Единый источник правды (SSOT), описание топологии, системные инварианты и реестр канонических артефактов зафиксированы в:
👉 **[PROJECT_PASSPORT.md](PROJECT_PASSPORT.md)**

## Основные разделы
* **`Карточки/`** — канонические регламенты, матрицы отказов (ADR) и стандарты безопасности.
* **`Промпты/`** — 4 эталонных инструмента (Протоколист смыслов, Взаимодействие, Кодирование/Архитектура, Генератор заданий).
* **`Входящие/`** — буфер первичного приема сырья (обнулен).
* **`Вахтенный_журнал/`** — журнал смен, передача контекста и фиксация инцидентов.
* **`.scripts/`, `dispatcher/`** — автоматизация вахты и системные скрипты.
