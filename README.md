# Лабораторный полигон

Рабочее пространство автоматизации, регламентов взаимодействия и ведения вахтенного журнала.

## Реестр уставных документов и регламентов

### Система взаимодействия
* `Система/Промпты/Системный_Промпт.md` — главный системный контракт взаимодействия, дисциплинарные барьеры и Правило нулевой толерантности.
* `Система/Промпты/Протокол_Заступления_На_Вахту.md` — протокол входа нового ассистента без потери контекста.
* `Система/Промпты/Регламент_Вахты.md` — регламент вахтенного цикла, разведение контуров логов и смысловых смен.

### Инженерные стандарты
* `Стандарт_Безопасного_Транспорта_И_CLI.md` — регламент безопасной работы с shell, экранирование Heredoc, предотвращение сбоев кавычек в zsh и изоляция скриптов.
* `Система/Регламенты/Стандарт_Скриптов_Raycast.md` — стандарт создания скриптов Raycast (единый пакет `Вахта`, emoji-иконки, звуковые сигналы).

### Инфраструктура и автоматизация
* `.scripts/vahta.py` — сборщик контекста смены и передача в буфер обмена (`pbcopy`).
* `.scripts/vahta.sh` — Raycast Script Command для вызова заступления на вахту.
* `.scripts/capture_error.py` — автономный перехватчик буфера обмена по горячей клавише для сброса любых ошибок в журнал.
* `ERROR_WORKFLOW.md` — регламент обработки ошибок и инцидентов оперативного контура.
* Алиас `вахта` — глобальная терминальная команда заступления на вахту.

### История и вехи
* `Вахтенный_журнал/` — хроника смысловых смен, закрытые вехи, архитектурные контракты.
