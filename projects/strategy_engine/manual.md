# Инструкция оператора: Блок создания и выполнения стратегий (Strategy Engine)

Блок предназначен для безопасной подготовки и детерминированного выполнения последовательностей системных действий без риска потери контекста и случайных сбоев.

---

## 1. Концепция двух контуров
- **Контур А (Планирование):** Создание карточки стратегии через скрипт `planner.py` или генерация агентом в чате. Фиксирует цель, запреты и атомарные шаги.
- **Контур С (Исполнение):** Запуск карточки скриптом `runner.py`. Выполняет команды строго по очереди в стандартном терминале macOS, останавливается при любой ошибке (exit code != 0).

---
