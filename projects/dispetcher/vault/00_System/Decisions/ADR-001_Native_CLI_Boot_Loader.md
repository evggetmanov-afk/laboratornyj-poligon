# ADR-001: Отказ от inline-команд шелла и переход на нативный загрузчик start/dispetcher

## 1. Контекст и проблема (Дано)
При попытке передачи многострочного Markdown через шелл терминал Zsh ломал кавычки и зависал в heredoc.

## 2. Рассмотренные альтернативы
- Base64: хрупко, ломает буфер.
- Ручной ввод в Obsidian: медленно для разбора очереди.

## 3. Принятое решение
- Запрет на ad-hoc inline-скрипты записи в шелле.
- Использование станка crystallize.py для заметок.
- Загрузчик start_dispetcher.py для копирования спецификаций в pbcopy.

## 4. Последствия
Среда изолирована, исключены сбои парсера Zsh.
