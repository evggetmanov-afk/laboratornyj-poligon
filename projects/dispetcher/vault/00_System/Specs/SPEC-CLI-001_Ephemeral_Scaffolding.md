# SPEC-CLI-001: Регламент детерминированной генерации артефактов через эфемерный скрипт

## 1. Суть правила
Любое создание или модификация файлов силами LLM оформляется как единый самодостаточный квант исполнения. Модель генерирует монолитную команду для терминала, исключающую ручное редактирование и буферные коллизии.

## 2. Физические обоснования
- **Изоляция оболочки:** Защита от раскрытия переменных и обратных апострофов.
- **Устранение когнитивного трения:** Оператор является контролирующим шлюзом, а не переносчиком текста.

## 3. Системные запреты
- Запрет ручной вставки в файлы через редактор.
- Запрет неконтролируемого молчания скриптов.
