# SPEC-ENV-001: Аппаратный контур и оркестрация рабочих станков

## 1. Среда исполнения
- Хост: macOS (MacBook Air, Zsh).
- Репозиторий: `Лабораторный_полигон`.
- Ядро хранилища: `projects/dispetcher/vault/`.

## 2. Аппаратная интеграция и сокеты
- **mpv IPC Socket:** `/tmp/mpvsocket` — используется для точной фиксации временных границ видеокадров без остановки воспроизведения.
- **Elgato Stream Deck:** профили кнопок привязаны к триггерам локальных утилит и быстрым операциям.

## 3. Маппинг утилит и алиасов
- `slicer.py` — нарезка медиапотока по меткам сокета mpv.
- `start_dispetcher.py` (или alias `vahta_open`) — атомарный захват кванта из очереди `01_Queue` в `03_Processing`, установка замка и экспорт контекста в `pbcopy`.
- `finish_dispetcher.py` (или alias `vahta_close`) — архивация кванта в `04_Processed`, обновление `INBOX_REGISTRY.md`, атомарный Git commit и снятие замка.
