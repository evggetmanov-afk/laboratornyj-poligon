# REQ-011: Очередь задач для агентного контура

## 1. Суть требования
Взаимодействие с внешними агентами организуется через файловую очередь задач в каталоге 01_Inbox/Agent_Queue/. Постановка задачи производится размещением файла спецификации в подкаталоге Pending/. После завершения обработки агент перемещает файл задачи в Processed/.

## 2. Ограничения (Negative Constraints)
- Агентам запрещено принимать задачи из свободных диалоговых потоков без создания файла спецификации в Pending/.
- Запрещено удалять файлы задач из очереди; история прогона сохраняется в Processed/.

## 3. Критерии приемки (DoD)
1. Развернуты директории 01_Inbox/Agent_Queue/Pending и 01_Inbox/Agent_Queue/Processed.
2. Определен формат файла постановки задачи агенту с явными входными параметрами и ожидаемым артефактом.
