# REQ-017: Верификация изменений через git diff

## 1. Суть требования
Перед любым коммитом оператор проводит построчный контроль изменений через git diff. Никакие скрытые, автоматические или несанкционированные правки не допускаются в историю репозитория.

## 2. Ограничения (Negative Constraints)
- Запрещено использование слепых команд фиксации без предварительной проверки статуса и диффа.
- Запрещено коммитить артефакты, содержащие случайные изменения форматирования или невидимые служебные символы.

## 3. Критерии приемки (DoD)
1. В регламенте закрытия такта шаг проверки git diff зафиксирован как обязательный.
