# REQ-026: Разделение облачного накопителя и локального контура

## 1. Суть требования
Облачный накопитель Google Drive используется как холодный архив и источник данных для Gemini NotebookLM. Локальный SSD с Git используется как горячий контур для работы со смысловыми карточками.

## 2. Ограничения (Negative Constraints)
- Категорически запрещено размещать активные деревья репозиториев Git внутри каталогов синхронизации Google Drive.

## 3. Критерии приемки (DoD)
1. Правило разделения контуров зафиксировано в Аксиоме VI Архитектурного манифеста.
