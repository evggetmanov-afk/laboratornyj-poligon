# REQ-009: Вектор состояния STATE.md как точка входа

## 1. Суть требования
Файл 00_System/STATE.md является единственной авторизованной точкой сборки оперативного контекста. Любой новый диалог с LLM и любая сессия человека начинаются с загрузки этого документа для мгновенного восстановления текущего вектора работ.

## 2. Ограничения (Negative Constraints)
- Запрещено существование нескольких файлов состояния (дубликаты типа STATE-1.md бракуются).
- Файл обязан содержать ровно один активный такт и конкретное атомарное действие (Action Item).

## 3. Критерии приемки (DoD)
1. Документ STATE.md размещен в корне 00_System/.
2. Поля last_tact, current_phase и status синхронизированы с Git-историей.
