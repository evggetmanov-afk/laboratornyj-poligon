# REQ-008: Сессионный журнал вахт оператора

## 1. Суть требования
Для борьбы с забыванием и когнитивной перегрузкой каждый рабочий подход (сессия/вахта) сопровождается короткой протокольной фиксацией: метка входа, список закрытых тактов и метка выхода с точкой возобновления в 00_System/Operations/Sessions/.

## 2. Ограничения (Negative Constraints)
- Запрещено закрывать рабочую сессию без синхронизации с 00_System/STATE.md.
- Журнал вахты не должен превращаться в пространное эссе: только факты, дельты и ссылки на затронутые артефакты.

## 3. Критерии приемки (DoD)
1. Определена структура имени файла вахты (session_YYYY_MM_DD_NN.md).
2. Описан регламент открытия и закрытия вахты в Runbooks.
