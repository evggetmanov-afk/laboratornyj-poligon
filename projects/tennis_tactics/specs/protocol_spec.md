# Спецификация тактического протокола анализа матчей (Tennis Tactics)

## 1. Архитектурный принцип (ABC / Двухконтурный анализ)
- **Слой А (Голос тренера):** Живой язык, психологические нюансы, наблюдения за ритуалами, взглядами и поведением в стрессе. Запрещено заменять живую речь стерильным канцеляритом.
- **Слой В (Физика корта):** Позиционирование, геометрия отскока, точки контакта мяча, тайминги между ударами, направление ветра/покрытия.
- **Слой С (Паспорт машины):** Детерминированные якоря для поиска и нарезки (`триггер`, `фаза_розыгрыша`, `исход`, таймкоды для mpv IPC).

---

## 2. Модель состояний розыгрыша (4 ключевые фазы)
1. **Фаза 0: Предстартовое состояние (Pre-serve)**
   - Ритуал подготовки, задержка дыхания, визуальный контакт с боксом/тренером.
   - Триггер готовности к риску / панике.
2. **Фаза 1: Ввод мяча (Serve / Return)**
   - Вектор подачи, глубина приема, позиция ног принимающего при замахе.
3. **Фаза 2: Контроль центра / Вскрытие угла (Rally Engine)**
   - Обмен ударами, глубина под заднюю линию, смена темпа (слайс/топспин).
4. **Фаза 3: Развязка (Decision Moment)**
   - Вынужденная ошибка, обводка, срыв в сетку, виннер.
