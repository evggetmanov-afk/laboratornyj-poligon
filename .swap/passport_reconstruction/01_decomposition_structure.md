# Декомпозиция разделов PROJECT_PASSPORT.md

## Раздел 1. Миссия и Назначение
- Статус: Статичный контур.
- Границы: Изоляция экспериментов, защита ядра системы, запрет самовольных действий.

## Раздел 2. Два раздельных контура среды
- Контур 1 (Рабочее ядро): SSD макбука под Git.
- Контур 2 (Операционный цикл): Google Диск для тяжелых данных и сырья.
- Шлюз: specs/Knowledge_Pipeline_Spec.md (~/Library/CloudStorage/GoogleDrive-.../Knowledge_Pipeline/).

## Раздел 3. Топология каталогов SSD
- methodology/ : Инварианты, правила надежности, ADR, матрица отказов.
- specs/ : Инженерные спецификации, протоколы шлюзов.
- scripts/ : Исполняемые утилиты автоматизации (vahta.py).
- projects/ : Изолированные направления (tennis_blitz и др.).
- .swap/ : Оперативный шлюз смены (TASK.md, утилиты ptr, menu).
- watch_log/ : Записи смен, вехи и история вахт.
- _quarantine/ : Буфер сомнительных файлов перед удалением/архивом.
- _draft/ : Песочница с нулевой ценностью.

## Раздел 4. Реестр операционных инвариантов (база для перевода в A-B-C)
- [01] Нативные документы (законно только записанное в файлах).
- [02] Простой язык (русский язык, глаголы действия, без канцелярита).
- [03] Структура рассуждений (от инварианта к специфике).
- [04] Детерминированный ход (прямые предложения без лишних вопросов).
- [05] Такт работы (ровно один шаг за раз).
- [06] Именование путей (только snake_case, без кириллицы и пробелов).
- [07] Создание новых папок (только с подтверждения оператора).
- [08] Конкурирующие гипотезы (файлы с говорящими именами рядом).
- [09] Защитный барьер кода (код строго по команде «напиши код» / «дай скрипт» / «делай»).
- [10] Протокол физической реальности (запрет глаголов прош. вр. без лога терминала).
- [11] Правка на месте и защита ядра (без слепых копий _v2; ядро правится только по подтверждению).
- [12] Контроль сессии и счетчик тактов ([Такт N/10] и стоп-линия вахты).
