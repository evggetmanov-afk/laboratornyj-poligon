# 🛟 Настольная шпаргалка оператора (Когнитивная разгрузка)

Вместо запоминания путей и флагов используйте простые команды в терминале.

| Что я хочу сделать? | Что ввести в терминал? | Что произойдет? |
| :--- | :--- | :--- |
| **Открыть главный пульт** | `меню` | Появится список действий с выбором по цифрам [1-6]. |
| **Узнать, что сейчас делать** | `задача` | Выведется содержимое текущего контракта (`.swap/TASK.md`). |
| **Найти карточку или правило** | `карта` | Выведется реестр смыслов из файла `INDEX.md`. |
| **Мозг «закипает»** | `смысл` | Выведется короткая памятка о том, в каком режиме вы сейчас работаете. |
| **Завершить работу/веху** | `сохрани` | Все измененные файлы добавятся в Git и улетят на GitHub. |

*Примечание: Если терминальные команды не работают, убедитесь, что вы перезапустили терминал или выполнили `source ~/.zshrc`.*
