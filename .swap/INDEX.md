## 3. БЫСТРЫЙ ТЕЗАУРУС
- **Атомарная сессия:** Одноразовый stateless-исполнитель.
- **Квант работы:** Неделимая единица задачи с проверяемым тестом.
- **Файл подкачки:** Буфер на диске (.swap/TASK.md).
- **Инвариант:** Неизменяемое архитектурное правило/табу.
- **Семантический дрейф:** Искажение сути при пересказе диалога.
- **Semantic Pointer:** Связка «ID — Суть — Физический адрес».

## 4. ДИРЕКТИВЫ ЗАПУСКА ДЛЯ ЧАТОВ
- **Для сессии осмысления:** «Работай по методологии A-B-C. Изучи .swap/INDEX.md, сформируй контракт кванта в .swap/TASK.md».
- **Для сессии исполнения:** «Читай .swap/TASK.md. Изменяй только файлы из СКОУПА. Проверь результат по КРИТЕРИЮ ПРИЕМКИ. Заполни СТАТУС».
