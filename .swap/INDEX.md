## 3. БЫСТРЫЙ ТЕЗАУРУС
- **Атомарная сессия:** Одноразовый чат-исполнитель без сохранения диалоговой истории.
- **Квант работы (Work Unit):** Неделимая единица задачи с проверяемым критерием сдачи.
- **Файл подкачки (Swap File):** Физический файл контракта на диске (`.swap/TASK.md`).
- **Инвариант:** Архитектурное правило или ограничение, запрещенное к нарушению.
- **Семантический дрейф:** Накопление искажений при пересказе контекста текстом.

## 4. ДИРЕКТИВЫ ЗАПУСКА ДЛЯ ЧАТОВ
- **Для сессии осмысления:** «Работай по методологии A-B-C. Изучи .swap/INDEX.md, сформируй контракт кванта в .swap/TASK.md».
- **Для сессии исполнения:** «Читай .swap/TASK.md. Изменяй только файлы из СКОУПА. Проверь результат по КРИТЕРИЮ ПРИЕМКИ. Заполни СТАТУС».
