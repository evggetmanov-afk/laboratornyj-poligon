# МЕТОДОЛОГИЯ A-B-C: ПЕРЕДАЧА ВАХТЫ И КВАНТОВАНИЕ

## ПОЛЯРНАЯ ЗВЕЗДА
Исключить человека из роли транспортного буфера между сессиями. Разделять архитектурное мышление и физическое исполнение.

## ТРИАДА КАРТОЧЕК
- Карточка A (Смысловая рамка): Цель текущей вехи, границы, жесткие инварианты.
- Карточка B (Протокол и декомпозиция): Алгоритм перехода от замысла к файлам.
- Карточка C (Атомарный квант): Файл подкачки .swap/TASK.md — конкретный контракт для исполнителя.

## ЖЕСТКИЕ ПРАВИЛА (ИНВАРИАНТЫ)
1. Никаких переносов сырых логов чата через буфер обмена.
2. Исполнитель работает строго в рамках поля СКОУП файла .swap/TASK.md.
3. Задача считается сданной только при выполнении объективного КРИТЕРИЯ ПРИЕМКИ.
4. Когнитивная эргономика: взаимодействие строится через интерактивное меню, русские алиасы и односложные триггеры без сложных параметров.
