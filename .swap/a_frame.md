# Рамка инвариантов системы (A-Frame)

## Полярная звезда проекта
Отработка автономных инженерных регламентов, протоколов взаимодействия с LLM и методологий организации знаний без потери фокуса и ключевых деталей.

## Архитектурные табу
1. Категорический запрет на разрушение изоляции контуров: Полигон не завязывается на код AI_Pipeline и не смешивается с предметной базой Tennis_Brain.
2. Запрет на пассивное складирование сырья без формулирования ключевого вопроса (`key_question`).
3. Запрет на неконтролируемое удаление входящих оригиналов (действует No-Delete Policy).
4. Запрет выдачи кода без триггера `+++` или «пиши код».
5. Запрет на скрытую эрозию документации: изменение в системе влечет обязательное обновление паспорта проекта.

## Стек и среда
* Платформа: macOS Sequoia, Apple Silicon, zsh, Python 3.11+.
* Хранилище знаний: Obsidian Vault (локальный репозиторий).
* Контроль версий: Git (origin/main).
