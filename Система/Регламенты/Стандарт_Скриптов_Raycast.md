# Стандарт разработки скриптов Raycast

## 1. Назначение
Регламент устанавливает обязательные требования к оформлению, группировке, метаданным и поведению пользовательских команд Raycast Script Commands в директории `.scripts/`.

## 2. Группировка в интерфейсе (Единый раздел)
* **Параметр `@raycast.packageName`:** обязан присутствовать в каждом скрипте без исключений.
* **Каноническое значение:** `Вахта` (для всех утилит управления сменами, контуром и хранилищем).
* **Цель:** скрипты проекта не размываются по общему списку Raycast, а группируются в единый монолитный блок команд.

## 3. Стандарт иконок (`@raycast.icon`)
* Иконка задается исключительно нативным символом Unicode Emoji (один символ).
* **Стилистическое правило:** семантическое соответствие вахтенной и инженерной тематике контура:
  * ⚓️ — заступление на вахту / сборка контекста смены.
  * 📝 — фиксация записей, создание карточек вахты.
  * 🔍 — поиск, валидация, просмотр последних записей.
  * ⚙️ — системные утилиты и синхронизация.

## 4. Обязательный манифест метаданных
Каждый исполняемый `.sh`-скрипт обязан начинаться со следующего блока метаданных Raycast:
- schemaVersion: 1
- title: лаконичное название действия на русском языке
- mode: silent (или compact/fullOutput при необходимости)
- icon: одиночный emoji из утвержденного набора
- packageName: Вахта
- description: краткое описание назначения
- author: Вахтенный помощник

## 5. Окружение и локализация
* Перед выполнением любой логики обязателен экспорт UTF-8 локали:
  export LANG="ru_RU.UTF-8"
  export LC_ALL="ru_RU.UTF-8"

## 6. Звуковая обратная связь
* **Успешное завершение:** `/System/Library/Sounds/Pop.aiff`
* **Отказ / Сбой:** `/System/Library/Sounds/Basso.aiff`


## Правило безопасности командной строки
При создании или обновлении скриптов через терминальную команду `python3 -c '...'` запрещено использовать вложенные одинарные кавычки и сложную интерполяцию строк. Все многострочные блоки кода должны передаваться через чистую запись файлов или отдельные скрипты во избежание ошибок парсинга оболочки `zsh`.
