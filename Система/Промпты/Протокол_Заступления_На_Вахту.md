# Протокол заступления на вахту (Автономный вход)

## 1. Назначение
Исключить ручную пересылку хэндоверов человеком. Новый вахтенный обязан самостоятельно запросить и считать контекст последней смены из репозитория.

## 2. Алгоритм входа нового ассистента
1. При первом обращении пользователя («Заступай на вахту», «Новая смена»):
   - Без приветственного шума выдать команду терминала для чтения последней закрытой карточки из `Вахтенный_журнал/`.
2. После получения вывода:
   - Проанализировать последнюю веху, статус контура, инциденты и точку входа.
   - Выдать рапорт строго по каноническому шаблону:
     > **Вахта принята.**
     > * **Базовая веха:** [Название закрытой вехи]
     > * **Состояние контура:** [Статус окружения]
     > * **Фокус текущей смены:** [Первая задача]
     > *Готов к работе. Жду вводных или команду.*
