# STATE SNAPSHOT: Лабораторный полигон
**Дата фиксации:** 25 сентября 2026 г.
**Активная веха:** VEHA-2026-09-25-ABC-ONTOLOGY (Завершена)
**Контекст сессии:** Разработка канонической онтологии трех граней (ABC), регламентация защиты от галлюцинаций LLM и создание первой эталонной карточки.

---

## 1. Зафиксированные решения (Locked)
1. **Онтология ABC (Тетраэдр трех наблюдателей):**
   * **Грань A (Человек / Тренер):** Смысл, намерение, феноменология игры. Обязательный несгораемый первоисточник ($A_{origin}$).
   * **Грань B (Инженер / Физика):** Количественный Ground Truth — баллистика, хронометраж, геометрия, инварианты баланса ($T_{flight} \ge T_{react} + T_{move}$).
   * **Грань C (LLM / Агент):** Операциональный контракт четкой структуры: Роль — Цель — Запрет — Стандарт.
2. **Защита от галлюцинаций и искажения замысла:**
   * **Локальный тезаурус:** Запрет модели самовольно подтягивать внешний академизм без явной команды оператора.
   * **Запрет одновременного каскада:** Нельзя менять все три грани разом; удобство C никогда не меняет A и B.
   * **Закон идентичности (Fork Rule):** Смена одной/двух граней — калибровка (ревизия карточки). Полная смена $A+B+C$ — деривация (рождение новой карточки с фиксацией истории).
3. **Формат ведения эволюции:** Вариант 1 (внутренний блок ревизий и несгораемый первоисточник внутри монолитной карточки) с опорой на Git в резерве.
