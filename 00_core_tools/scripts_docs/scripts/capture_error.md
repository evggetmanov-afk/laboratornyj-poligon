# Инструмент: capture_error (.scripts/capture_error.py)

## 1. Суть
Автономный перехват текста ошибки из буфера обмена с немедленной регистрацией инцидента.

## 2. Способы вызова
- **Прямой путь:** `python3 .scripts/capture_error.py`

## 3. Алгоритм работы
1. Читает буфер обмена (`pbpaste`).
2. Проверяет наличие трассировки стека или кода ошибки.
3. Формирует блок инцидента в журнале по правилу Logging First.

## 4. Входы и выходы
- **Входы:** Буфер обмена macOS.
- **Выходы:** Запись инцидента в журнал.

## 5. Диагностика сбоев
- *Симптом:* Пустой буфер обмена при вызове.
  - *Решение:* Скопировать сообщение терминала об ошибке перед вызовом.
