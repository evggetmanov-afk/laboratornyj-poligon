# Инструмент: vahta (.scripts/vahta.sh ➔ vahta.py)

## 1. Суть
Агрегатор оперативного контекста смены для сдачи/приема вахты без ручного набора отчетов.

## 2. Способы вызова
- **Алиас:** `вахта`
- **Пункт меню:** Пункт в меню оператора
- **Прямой путь:** `.scripts/vahta.sh` или `python3 .scripts/vahta.py`

## 3. Алгоритм работы
1. `vahta.sh` проверяет окружение и вызывает исполняемый модуль `vahta.py`.
2. Модуль опрашивает статус Git-репозитория (`git status`, последние коммиты).
3. Сканирует актуальные файлы смен в `Вахтенный_журнал/`.
4. Формирует форматированный Markdown-дайджест и сбрасывает его в буфер `pbcopy`.

## 4. Входы и выходы
- **Входы:** Метаданные Git, файлы журнала.
- **Выходы:** Текст дайджеста в системном буфере обмена macOS.

## 5. Диагностика сбоев
- *Симптом:* Пустой буфер обмена.
  - *Решение:* Проверить работу команды `pbcopy` в терминале.
