# Инструмент: template_action (.scripts/template_action.sh)

## 1. Суть
Шаблонный генератор заготовок для создания новых скриптов автоматизации с соблюдением системных стандартов.

## 2. Способы вызова
- **Прямой путь:** `.scripts/template_action.sh "Имя_действия"`

## 3. Алгоритм работы
1. Принимает имя новой утилиты.
2. Создает парную заготовку (`.sh` + `.py`) с прописанными путями, обработкой аргументов и правами `+x`.

## 4. Входы и выходы
- **Входы:** Название утилиты.
- **Выходы:** Каркас скрипта в каталоге `.scripts/`.

## 5. Диагностика сбоев
- *Симптом:* Не указано имя действия при вызове.
  - *Решение:* Передать аргумент имени: `.scripts/template_action.sh my_action`.
