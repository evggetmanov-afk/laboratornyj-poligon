# Сводный реестр исполняемых скриптов и утилит системы

## 1. Архитектурное разделение зон
* **Зона `.scripts/`:** Общесистемная инфраструктура проекта (вахтенный протокол, логирование смен, перехват ошибок, обработка буфера).
* **Зона `.swap/bin/`:** Оперативный инструментарий протокола A-B-C и когнитивной эргономики оператора.

---

## 2. Группировка и адресные указатели (Semantic Pointers)

### Группа 1: Вахта и контекст смен (.scripts/)
| Утилита / Связка | Назначение | Способ вызова | Карточка паспорта |
| :--- | :--- | :--- | :--- |
| `vahta.sh` ➔ `vahta.py` | Сбор статуса смены и коммитов в буфер | Алиас `вахта`, пункт меню | `_system_spec/scripts/vahta.md` |
| `shift_note.py` | Инициализация и ведение заметки текущей смены | Вызов по требованию | `_system_spec/scripts/shift_note.md` |
| `close_shift_++++.py` | Протокол закрытия смены по ключевому триггеру | Вызов по требованию | `_system_spec/scripts/close_shift.md` |
