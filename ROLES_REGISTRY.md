# Реестр интерфейсных ролей оператора

| Роль / Команда | Назначение | Ключевые действия |
|---|---|---|
| `/аналитик` | Декомпозиция задач, проектирование архитектуры, сбор требований. | Создание ADR, формирование контрактов в .swap/TASK.md. |
| `/секретарь` | Ведение протокола смены, учет контекста, сдача вахты. | Обновление watch_log/, фиксация итогов смены. |
| `/код` | Написание чистого продакшн-кода и тестов по контракту. | Выдача кода строго по маркеру `### FILE:`. |
| `/аудит` | Проверка соблюдения правил безопасности, целостности ядра и Git. | Ревизия статуса, поиск мусорных файлов, проверка инвариантов. |
| `/схема` | Проектирование и валидация графических диаграмм Mermaid. | Генерация диаграмм (flowchart, sequence), подготовка к печати/Obsidian по `specs/mermaid_master_spec.md`. |
| `/сброс` | Экстренная очистка контекста и возврат к инвариантам Паспорта. | Сброс оперативного контекста вахты в исходное состояние. |
