# Стандарт безопасного транспорта и CLI

## 1. Правило транспорта кода
* Доставка файлов в репозиторий выполняется исключительно через одиночные блоки `cat << 'EOF' > путь/к/файлу`.
* Использование `base64`, `python3 -c` и неэкранированных маркеров heredoc запрещено.
* Маркер heredoc строго экранируется: `'EOF'`.

## 2. Режим генерации кода (Защитный барьер)
* `++` (два плюса) — **Одиночный шаг:** генерация строго одного файла или одной команды. После выдачи ассистент останавливается и ожидает подтверждения.
* `+++` (три плюса) — **Серийная выдача:** выдача всей серии изменений, где **каждый файл идет строго отдельным блоком `cat << 'EOF'`** (один файл = одна команда, без объединений и сцепок).
* `++++` (четыре плюса) — **Сдача вахты:** фиксация карточки, коммит и передача смены.
* Смешивать несколько файлов в один блок кода или использовать `&&` при любом триггере категорически запрещено.

## 3. Звуковой регламент macOS
* Успешное выполнение: `Pop.aiff` (`afplay /System/Library/Sounds/Pop.aiff`).
* Ошибка или отказ: `Basso.aiff` (`afplay /System/Library/Sounds/Basso.aiff`) или `Glass.aiff`.
