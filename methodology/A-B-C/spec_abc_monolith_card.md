# Методология конвейера ABC и стандарт карточек

## 1. Назначение
Преобразование живого тренерского и исследовательского опыта в проверяемые инженерные правила без семантического вымывания сути нейросетью (LLM).

---

## 2. Три грани сущности (A – B – C)

### Грань A (Замысел / Голос)
* **Суть:** Прямой опыт, целеполагание и наблюдения оператора на корте или за рабочим столом.
* **Инвариант:** Обязательный блок первоисточника (`A_origin`). ИИ **категорически запрещено** перефразировать, стилистически сглаживать или подгонять под академические шаблоны прямую речь автора.

### Грань B (Среда / Инженерный базис)
* **Суть:** Объективная физическая реальность: геометрия, хронометраж, биомеханика корта, либо измеримые ограничения вычислительной среды (файловая система, токены, точки отказа).
* **Инвариант:** Единственный арбитр реализуемости. Если параметр среды не создает измеримую точку отказа — он удаляется как шум. Запрещено использовать субъективные оценки («удобнее», «красивее»).

### Грань C (Контракт для LLM)
* **Суть:** Детерминированное задание для исполнения моделью или скриптом.
* **Формула контракта:**
  * **Роль:** Ракурс и фильтр мышления агента.
  * **Цель:** Конечный осязаемый артефакт текущего шага.
  * **Запрет (Negative Constraints):** Четкие границы безопасности (без кода без команды, без домыслов, без удаления).
  * **Стандарт:** Формат сдачи (Markdown, Frontmatter, синтаксис).

---

## 3. Жизненный цикл и правила ведения карточек
1. **Монолитность (1 сущность = 1 файл):** Все три грани сущности живут внутри одного файла. Разделять грани по отдельным документам запрещено.
2. **Направление калибровки:** Изменения идут строго однонаправленно: `A -> B -> C`.
3. **Закон идентичности (Правило ветвления):**
   * Уточнение одной или двух граней — это **калибровка** (фиксируется новой ревизией в текущей карточке).
   * Одновременное коренное изменение всех трех граней ($A + B + C$) признается **деривацией (новой сущностью)**. Старая карточка замораживается как исторический факт, рядом создается новая с новым ID.
4. **Приоритет локального тезауруса:** Терминология опирается исключительно на локальный словарь репозитория. Внешние академические понятия привлекаются только по прямой команде оператора.
