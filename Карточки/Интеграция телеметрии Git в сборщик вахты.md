# Интеграция телеметрии Git в сборщик вахты

## 1. Замысел и ценность
На текущий момент утилита `.scripts/vahta.py` собирает контекст смены исключительно на основе физических файлов на диске. 
Цель задачи — внедрить слой Git-телеметрии, чтобы:
1. В заголовке смены автоматически фиксировался хэш текущего коммита (`git rev-parse --short HEAD`).
2. Осуществлялась автоматическая проверка чистоты рабочего дерева (`git status --porcelain`).
3. Срабатывал `Remote Guard` — проверка паритета локальной ветки с удаленным репозиторием (`origin/main`).

## 2. Архитектурный прототип (Заготовка для .scripts/vahta.py)
При реализации добавить вызов git rev-parse, git status и проверку origin/main с fallback-режимом при отсутствии сети.

## 3. Критерии приемки
- Контекст смены в буфере содержит блок телеметрии Git.
- При наличии незакоммиченных изменений или отставании от origin/main выдается предупреждение.
- При отсутствии сети или сбое Git сборщик вахты не падает, а переходит в автономный режим.
