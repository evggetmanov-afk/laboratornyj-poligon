# Инструмент: view_last_entry (.scripts/view_last_entry.sh)

## 1. Суть
Экспресс-просмотр последней зафиксированной записи вахтенного журнала прямо в терминале.

## 2. Способы вызова
- **Пункт меню:** Пункт в меню оператора
- **Прямой путь:** `.scripts/view_last_entry.sh`

## 3. Алгоритм работы
1. Находит самый свежий файл в каталоге `Вахтенный_журнал/`.
2. Выводит последние 25 строк файла на экран терминала.

## 4. Входы и выходы
- **Входы:** Файлы в каталоге `Вахтенный_журнал/`.
- **Выходы:** Вывод текста в `stdout`.

## 5. Диагностика сбоев
- *Симптом:* Каталог журнала пуст.
  - *Решение:* Создать заметку через скрипт `shift_note.py`.
