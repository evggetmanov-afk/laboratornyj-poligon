# Инструмент: close_shift (.scripts/close_shift_++++.py)

## 1. Суть
Автоматизированный протокол закрытия рабочей смены при получении триггера `++++`.

## 2. Способы вызова
- **Прямой путь:** `python3 .scripts/close_shift_++++.py`

## 3. Алгоритм работы
1. Проверяет чистоту рабочего дерева Git.
2. Архивирует временные буферные отметки.
3. Проставляет отметку о закрытии смены в актуальном логе вахты.

## 4. Входы и выходы
- **Входы:** Текущие файлы вахтенного журнала.
- **Выходы:** Итоговая отметка о сдаче вахты в логе.

## 5. Диагностика сбоев
- *Симптом:* Отказ из-за незафиксированных изменений.
  - *Решение:* Сделать предварительный коммит через `сохрани`.
