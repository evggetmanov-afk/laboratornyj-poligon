# Инструмент: ptr (.swap/bin/ptr)

## 1. Суть
CLI-навигатор по реестру атомов, системным манифестам, буферу обмена и блокноту NotebookLM.

## 2. Способы вызова
- **Алиасы:** `задача` (`ptr task`), `карта` (`ptr list`), `смысл` (`ptr guide`).
- **Копирование карточки:** `.swap/bin/ptr copy [ID]`.
- **Открыть NotebookLM:** `.swap/bin/ptr open`.

## 3. Алгоритм работы
1. Принимает аргумент командной строки (`list`, `task`, `guide`, `open`, `copy <ID>`).
2. Фильтрует нужный блок из `.swap/INDEX.md` или `.swap/docs/abc_vault.md` через `awk`.
3. Команда `copy` направляет блок карточки в поток `pbcopy`.
4. Команда `open` считывает URL из `INDEX.md` и открывает браузер.

## 4. Входы и выходы
- **Входы:** `.swap/INDEX.md`, `.swap/docs/abc_vault.md`, `.swap/TASK.md`.
- **Выходы:** Текст в терминал, запись в буфер обмена macOS.

## 5. Диагностика сбоев
- *Симптом:* `ptr open` выдает ошибку адреса.
  - *Решение:* Заполнить корректный URL блокнота в `INDEX.md`.
