# Инструмент: validate_scripts (.scripts/validate_scripts.py)

## 1. Суть
Тестирование синтаксиса и проверка целостности всех исполняемых скриптов репозитория.

## 2. Способы вызова
- **Пункт меню:** Пункт в меню оператора
- **Прямой путь:** `python3 .scripts/validate_scripts.py`

## 3. Алгоритм работы
1. Сканирует каталоги `.scripts/` и `.swap/bin/`.
2. Проверяет наличие прав на исполнение (`+x`).
3. Запускает проверку синтаксиса Python (`py_compile`) и Bash (`bash -n`).
4. Выводит итоговую зеленую/красную матрицу проверки.

## 4. Входы и выходы
- **Входы:** Исполняемые файлы в `.scripts/` и `.swap/bin/`.
- **Выходы:** Отчет о валидации в терминале.

## 5. Диагностика сбоев
- *Симптом:* Красный статус утилиты.
  - *Решение:* Открыть карточку скрипта и проверить синтаксис.
